## Installation & Setup

After purchasing vCard, follow these steps to set up your portfolio:

### Download the Template:

After completing your purchase on Buy Me a Coffee, download the ZIP file containing the template.
Extract the ZIP to a folder on your computer.

### Customize the Content:

- Open the index.html file in a text editor (e.g., VS Code, Sublime Text).
- Update the text (e.g., name, bio, projects, contact info) to reflect your personal details.
- Replace placeholder images in the ./assets/images/ folder with your own (e.g., avatar, project thumbnails).
- Modify the style.css file to adjust colors, fonts, or layout if desired.

### Test Locally:

- Open index.html in a web browser to preview your changes.
- Ensure all images, links, and interactive features (e.g., theme toggle, portfolio filter) work as expected.

### Deploy Online:

- Upload the entire project folder to your web hosting service (e.g., Netlify, GitHub Pages, Vercel).
- Use an FTP client or hosting platform’s deployment tools to publish the files.
- Verify the live site to confirm responsiveness and functionality.

## Prerequisites

- Before setting up vCard, ensure you have:
- A text editor for customizing HTML/CSS/JavaScript (e.g., VS Code).
- A modern web browser (e.g., Chrome, Firefox, Edge) for testing.
- Basic knowledge of HTML, CSS, and JavaScript for personalization.
- (Optional) Web hosting for deploying the portfolio online.
